## 1. Юридична та фінансова база (Що оформляти офіційно)

Для офіційного прийому благодійних внесків та захисту від податкових ризиків громадська організація повинна мати належний юридичний статус:

### 1.1. Статус неприбутковості
- [ ] **Витяг з Єдиного державного реєстру (ЄДРПОУ):** переконатися, що назва та реквізити відповідають статутним документам.
- [ ] **Ознака неприбутковості 0032** (Громадські об'єднання): наявність організації у Реєстрі неприбуткових установ та організацій ДПС. Це звільняє благодійні пожертви від оподаткування на прибуток.

### 1.2. Банківський рахунок неприбуткової організації
- [ ] Відкриття поточного рахунку ГО у форматі **IBAN** в українському банку (Monobank, ПриватБанк, Райффайзен, Укрсиббанк).
- [ ] Обов'язково відкрити **валютний рахунок (EUR / USD)** для можливості отримувати міжнародні гранти та SWIFT-перекази від європейських молодіжних фондів (Erasmus+, European Youth Foundation).

### 1.3. Публічні юридичні документи на сайті
Закон України «Про благодійну діяльність та благодійні організації» та Закон «Про захист персональних даних» вимагають розміщення на сайті таких документів:
1. **Публічна оферта про благодійну пожертву (Договір публічної оферти):**
   - Визначає, що внесок є добровільною безповоротною благодійною допомогою на статутну діяльність ГО.
   - Дає право організації перерозподіляти кошти між проєктами, якщо ціль проєкту вже закрито.
2. **Політика конфіденційності (Privacy Policy):**
   - На сторінці `/privacy-policy` вказати офіційні контакти ГО, мету збору даних волонтерів і донорів (ім'я, email, телефон), термін збереження та права суб'єкта даних.
3. **Згода на обробку персональних даних:**
   - Чекбокс у модальних вікнах волонтерства та зворотного зв'язку (вже реалізовано, потрібно підтвердити юридичну формулу).

## 2. Інфраструктура, хостинг та сервери (Що піднімати)

### 2.1. Доменне ім'я (Domain Name)
* **Рекомендована зона:**
  * `.org.ua` (наприклад, `map.org.ua`) — класичний авторитетний домен для українських ГО.
  * `.org` (наприклад, `map-youth.org`) — для виходу на європейських партнерів та донорів.
* **Реєстратори:** CityHost, Nic.ua, Namecheap, Cloudflare Registrar.
* **Вартість:** ~300–600 грн/рік.

### 2.2. DNS та CDN захист (Cloudflare)
* **Підключити безкоштовний план Cloudflare:**
  * Автоматичний безкоштовний **SSL-сертифікат (HTTPS)**.
  * Захист від DDoS-атак та шкідливих ботів.
  * Глобальне кешування статичних файлів і зображень (прискорює завантаження сайту у 3-5 разів).
  * Захист від спаму: безкоштовна невидима перевірка **Cloudflare Turnstile** (альтернатива Google reCAPTCHA).

### 2.3. Хостинг додатку Next.js

| Параметр | Варіант 1: Vercel (Рекомендовано ⭐) | Варіант 2: VPS + Docker |
| :--- | :--- | :--- |
| **Для чого** | Нульовий клопіт з Linux-серверами, автоматичний деплой з GitHub | Повний контроль над сервером і базою |
| **Хостинг** | Vercel (Hobby / Pro) | Hetzner Cloud (CX22) / DigitalOcean (~€4-7/міс) |
| **Деплой** | `git push main` -> автозбірка | GitHub Actions -> SSH / Docker Compose |
| **Сервер** | Serverless Edge Network по всьому світу | Ubuntu 24.04 LTS + Docker + Caddy (авто-SSL) |
| **Адміністрування** | 0 годин на місяць | 2-4 години на місяць (оновлення OS, бекапи) |

> **Рекомендація:** Починати з **Vercel** — він ідеально оптимізований під Next.js 16 App Router, забезпечує миттєве завантаження сторінок та відсутність витрат на системного адміністратора.

### 2.4. Промислова база даних (PostgreSQL)
Зараз у коді реалізовано роботу з PostgreSQL + аварійний JSON-фолбек. Для продакшну піднімається керована хмарна база:
* **Supabase (PostgreSQL 16):**
  * Безкоштовний тариф: до 500 МБ БД, щоденні автоматичні бекапи, Connection Pooling через Supavisor, панель керування даними у браузері.
  * Або **Neon.tech** (Serverless PostgreSQL з автоматичним масштабуванням).
* **Схема бази даних:** виконати створення таблиць (`donations`, `inbox`, `projects`, `news`, `team`) згідно з файлом [docker/init.sql](file:///e:/work/MAP/docker/init.sql).

### 2.5. Хмарне сховище зображень (Media Storage)
Замість збереження великих фотографій новин та проєктів на локальний диск:
* Підключити **Cloudflare R2** або **Supabase Storage** (безкоштовно до 10 ГБ/міс).
* Пряме завантаження зображень через Drag-and-Drop в адмін-панелі.

## 3. Платіжні системи та збір пожертв

Зараз у модалці донату встановлено демонстраційну затичку. Для реального прийому коштів потрібно підключити офіційний платіжний шлюз:

### 3.1. Monobank Еквайринг для ГО (Monobank Donate)
* **Умови:** Monobank надає спеціальні умови для благодійних фондів та ГО (комісія 0% або пільговий тариф).
* **Що потрібно:**
  1. Мати відкритий рахунок ГО у Monobank.
  2. Подати заявку на підключення інтернет-еквайрингу в кабінеті Monobank для бізнесу.
  3. Отримати `X-Token` (API Token).
* **Технічна реалізація:**
  * Створити серверний ендпоінт створення інвойсу: `POST /api/donations/create-invoice`.
  * Створити вебхук `POST /api/webhooks/monobank`: коли донор оплачує карткою або Apple Pay, Monobank шле сигнал, наша база даних фіксує суму, і лічильник на картці проєкту **автоматично зростає**.

### 3.2. LiqPay (ПриватБанк) / WayForPay
* Резервний шлюз для прийому карткових платежів будь-яких банків світу, а також через термінали самообслуговування.
* Тариф для благодійних організацій: знижена комісія ~1.5%.

### 3.3. Stripe / PayPal (Міжнародні донати)
* Для прийому донатів у EUR/USD від діаспори та іноземних громадян (Stripe підтримує Apple Pay/Google Pay для іноземних карток без конвертаційних збоїв).

## 4. Безпека та конфігурація середовища

### 4.1. Зміна тестових секретів на криптографічно стійкі
У файлі `.env.local` на продакшн-сервері обов'язково замінити дефолтні ключі:
```env
# 1. Підключення до БД (Supabase / Neon з sslmode=require)
DATABASE_URL="postgres://postgres.xxxx:your_secure_password@aws-0-eu-central-1.pooler.supabase.com:6543/postgres?sslmode=require"

# 2. Криптографічний секрет для HMAC-SHA256 сесій (мінімум 64 випадкових символи)
# Згенерувати: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
SESSION_SECRET="f9b4c81a2e34567890abcdef1234567890abcdef1234567890abcdef12345678"

# 3. Паролі ролей адмін-доступу (використовувати надійні паролі від 16 знаків)
ADMIN_PASSWORD="Strong_Admin_Pass_2026!#"
EDITOR_PASSWORD="Editor_Secure_Pass_2026!$"
COORDINATOR_PASSWORD="Coord_Secure_Pass_2026!%"

# 4. Telegram Bot API
TELEGRAM_BOT_TOKEN="123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
TELEGRAM_CHAT_ID="-1001234567890"

# 5. Платіжні токени
MONOBANK_API_TOKEN="u_your_monobank_token_here"
```

### 4.2. Налаштування резервного копіювання (Backups)
* Увімкнути щоденні автоматичні снапшоти бази даних (у Supabase налаштовано автоматично з глибиною збереження 7 днів).
* Експорт резервної копії раз на тиждень на захищений диск команди.

## 5. Операційні інтеграції

### 5.1. Корпоративна пошта на власному домені
* **Google Workspace for Nonprofits:**
  * Google надає **БЕЗКОШТОВНО** повноцінний пакет Google Workspace (Gmail, Google Drive, Meet, Docs) для неприбуткових організацій в Україні через валідацію в **TechSoup Ukraine**.
  * Скриньки для команди: `info@map.org.ua`, `president@map.org.ua`, `projects@map.org.ua`.
* Налаштувати поштові DNS-записи: **MX**, **SPF**, **DKIM** та **DMARC** (гарантує 100% доставку листів і захист від спам-фільтрів).

### 5.2. Telegram CRM для команди
* Уже підготовлено модуль [src/lib/telegram.ts](file:///e:/work/MAP/src/lib/telegram.ts):
  * При подачі заявки новим волонтером або надсиланні запиту через контакти бот надсилає структуроване повідомлення у внутрішній Telegram-чат координаторів.
  * Потрібно зареєструвати бота через `@BotFather`, додати його у чат команди ГО та вказати `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.

## 6. SEO, аналітика та гранти для ГО

### 6.1. Аналітика відвідуваності
* Підключити **Google Analytics 4 (GA4)** або приватну європейську аналітику **Plausible / Umami** (без використання сторонніх кукі).
* Налаштувати відстеження ключових цілей (конверсій):
  * Клік на кнопку «Підтримати» (Donate).
  * Успішне відправлення анкети волонтера.
  * Перегляд річного звіту.

### 6.2. Пошукова оптимізація (SEO)
* Додати динамічний файл `sitemap.xml` та `robots.txt` у Next.js (`src/app/sitemap.ts`).
* Зареєструвати сайт у **Google Search Console** та надіслати Sitemap для швидкої індексації.
* Перевірити Open Graph (OG) метатеги — при надсиланні посилання на сайт у Telegram чи Facebook має відображатися красивий брендований банер з описом організації.

### 6.3. Грант $10,000/місяць на рекламу (Google Ad Grants)
* Для зареєстрованих ГО Google надає грант у розмірі **$10,000 на місяць** на безкоштовну контекстну рекламу в пошуку Google.
* Це дозволить без бюджету залучати тисячі молодих людей на освітні тренінги, програми обміну та знаходити донорів по всій Україні та ЄС.
