# Веб-платформа MAP (Association for Youth Development and Social Integration)

Сучасна повнофункціональна веб-платформа для молодіжної організації MAP із нульовим часом оновлення контенту (**Zero-Rebuild Real-Time CMS**), повноцінним інлайн-редагуванням, підтримкою YouTube/фото у статтях та базою даних PostgreSQL у Docker.

---

## 🚀 Швидкий запуск на локалхості (Localhost)

### 1. Запуск бази даних та сервісів у Docker
У корені проєкту виконайте:
```bash
npm run docker:up
```
Ця команда автоматично:
* Завантажує та піднімає контейнер **PostgreSQL 16** (`map_postgres`) на порту `5432`;
* Виконує скрипт `docker/init.sql`, який створює всі необхідні таблиці та наповнює їх початковими даними;
* Запускає веб-панель керування базою даних **Pgweb** на `http://localhost:8080`.

### 2. Запуск веб-сайту (Next.js)
```bash
npm run dev
```
Сайт відкривається за адресою:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 📊 Доступні локальні сервіси

| Сервіс | Адреса | Призначення | Облікові дані |
| :--- | :--- | :--- | :--- |
| **MAP Web App** | `http://localhost:3000` | Публічний сайт та адмін-режим | Режим адміна: кнопка «Вхід для команди» |
| **Pgweb (DB Admin)** | `http://localhost:8080` | Зручний веб-інтерфейс для перегляду та редагування таблиць PostgreSQL | Підключено автоматично |
| **PostgreSQL 16** | `localhost:5432` | Реляційна база даних | `user: map_admin`<br>`password: map_secret_password`<br>`db: map_db` |

## 🛠️ Корисні команди

* **Запустити базу даних та веб-панель:**
  ```bash
  npm run docker:up
  ```
* **Зупинити контейнери:**
  ```bash
  npm run docker:down
  ```
* **Переглянути логи контейнерів:**
  ```bash
  npm run docker:logs
  ```
* **Зібрати продакшн-білд:**
  ```bash
  npm run build
  ```

## 🛡️ Як працює режим адміністратора (Real-Time CMS)
1. Відкрийте [http://localhost:3000](http://localhost:3000).
2. Натисніть **«Вхід для команди»** у верхньому правому кутку (або **«No login»** у футері сайту).
3. Після активації режиму:
   * На головній сторінці з'являється кнопка **`+ Додати нову публікацію`** (з модальним вікном створення статті, форматуванням тексту, фото та YouTube-посиланням);
   * На картках новин та проєктів з'являються кнопки швидкого редагування ✏️ та видалення 🗑️;
   * Тексти гасел банера та контактів можна редагувати прямо на місці;
   * На індивідуальній сторінці новини доступний вбудований блоковий редактор;
   * Усі зміни негайно зберігаються у PostgreSQL та одразу стають доступними користувачам без перезбирання (`build`) сайту.
